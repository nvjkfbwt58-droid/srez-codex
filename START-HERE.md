# Срез — текущие исходники, 30 сентября 2026

Панель для разных сетей: аудитории, акции, купоны, партнёры, стили и карта магазинов. Это версия «Среза», а не отдельная панель «Пивоман».

## Запуск

Нужны Node.js 22.13+ и pnpm.

```sh
pnpm install --frozen-lockfile
cp .env.example .env
pnpm dev
```

Панель: http://127.0.0.1:5198. Сервер: http://127.0.0.1:4198. В `.env` установите `PORT=4198`, если меняете пример конфигурации. Используйте новую папку `DATA_DIR` для локальных данных.

Ключи API, рабочая база и личные загрузки не включены. AI требует собственного серверного ключа и настройки провайдеров и бюджета в `.env`. Без настройки внешние AI-запросы отключены.

## Проверки

```sh
pnpm exec tsx --test tests/catalogLibrary.test.ts tests/audienceWorkspace.test.tsx tests/couponWorkflow.test.ts
pnpm build
```

До публикации пройдены 17 проверок сценариев аудитории/каталога/купонов; после последних визуальных изменений пройдены TypeScript и сборка frontend. Проверены настольная и мобильная раскладки карты, полноэкранный режим и возврат. Полный набор старых тестов повторно не запускался; в нём остаются проверки прежних финансовых сценариев.

## Устройство

`src/` — React frontend. `server/` — Express backend и AI-интеграции. `db/` — схема/миграции. `public/` — публичные материалы. `tests/`, `e2e/` — проверки. Зависимости зафиксированы в `pnpm-lock.yaml`.

Данные для демонстрации синтетические. Реальные кассы, Битрикс и выдача купонов в клиентское приложение требуют отдельной интеграции. Старые AUDIT-HANDOFF.md и другие отчёты описывают предыдущие этапы; audit-seed.ts содержит старые финансовые ожидания и не проверен для этой версии.

Эта публикация содержит исходники. Она сама по себе не обновляет GitHub Pages и не размещает backend.

## Публикация Pages

Workflow проверяет 23 теста браузерного хранения, каталога, аудитории и купонов, затем TypeScript и production-сборку Pages. Полный набор локально: 59 пройдено, 6 ошибок (старые финансовые/assistant ожидания и окружение серверных тестов). Это не подтверждение полной серверной регрессии.
