# Срез для сетей: карта магазинов · 22.09.2026

## Рабочая версия

Отдельная папка `srez-network`. Замороженные исходники `srez-codex`, их ZIP и версия Пивомана не изменялись. GitHub-публикация не выполнялась.

- Карта: http://127.0.0.1:5198/stores
- Обзор: http://127.0.0.1:5198/overview
- API: http://127.0.0.1:4198/api/status

## Что показал анализ и что исправлено

1. Выбор магазинов был доступен только списком; перехода от географии к действиям не было. Добавлен раздел «Магазины», карточка перехода в обзоре и переход на карту из общих фильтров.
2. В обзоре выводились первые четыре строки всех магазинов, даже когда выбран другой набор. Теперь таблица соответствует выбранным точкам.
3. Сброс на всю сеть мог снова подставлять магазин из настройки по умолчанию. Явное `stores=all` теперь отделено от отсутствия параметра.
4. Новая карта использует существующие расчёты, включая возвраты и сравнение с предыдущим периодом. Средний чек выбранных точек считается по общей выручке и количеству чеков, а не усреднением средних.
5. Переход к аналитике сохраняет период и параметры адресной строки. Создание кампании переносит выбранные магазины в предложение; кампания создаётся черновиком без назначения купонов.

## Интерфейс карты

Двенадцать демонстрационных точек около московских районов из существующего справочника. Их координаты не являются реальными адресами магазинов. Поиск, район, сортировка, множественный выбор, показатели, карточка точки с динамикой, CSV, масштаб, общий вид, полный экран с кнопкой возврата. На мобильном карта находится над списком, действия перенесены в отдельные строки. Системное уменьшение движения учитывается.

Нажатие на первую точку при выборе всей сети выбирает только её; следующие нажатия добавляют или убирают точки. Чекбоксы списка меняют выбор независимо. Карточка открывается также нажатием на название магазина. «Применить» обновляет общий фильтр, «Аналитика» сразу открывает продажи выбранного набора. Пустой выбор не запускает действие над всей сетью.

Основная карта — MapLibre GL JS 5.6.0, подложка [OpenFreeMap Positron](https://openfreemap.org/quick_start/) с сохранением встроенной атрибуции OpenStreetMap/OpenMapTiles. Цвета воды, зелени и построек адаптируются к оформлению Среза. Платный картографический ключ не требуется.

Библиотека карты и её CSS загружаются отдельно, только при открытии карты. Плотность рендера ограничена 1.5; масштабирование колёсиком выключено, чтобы не мешать прокрутке страницы. Сенсорный масштаб и кнопки остаются доступны. При недоступности подложки, WebGL или при выборе «Лёгкая схема» работает локальная SVG-схема с выбором точек, приближением и перемещением. Она явно помечена как условная география. Наклон доступен только на географической карте.

## Запуск и сохранённые функции

Проверено: Node 24.19.0, pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

В этой локальной копии `.env` сохранён приватно; PORT изменён на 4198, DATA_DIR — на `./storage`. SQLite скопирован через backup API, включая существующий журнал бюджета, материалы скопированы в отдельную папку. Счётчики разных запущенных копий впоследствии не синхронизируются. Не следует считать локальный бюджет балансом аккаунта.

Для новой установки без AI: скопировать `.env.example` в `.env`, оставить ключ пустым и использовать `IMAGE_PROVIDER=none`, `ASSISTANT_PROVIDER=none`. Для сохранения изображений/версий нужен запущенный backend. Обзор, продажи, покупатели, кампании, купоны, студия, стиль сети, результаты, помощник, данные и настройки остаются в этой копии.

```sh
pnpm build
pnpm start
```

Production-сборка отдаёт приложение и API на 4198. Локальный запуск использует только loopback, без внешней публикации.

- TypeScript, Vite frontend build, esbuild backend build — успешно.
- `node --import tsx --test tests/networkMap.test.tsx` — 4/4: выбор/URL, перенос в кампанию, сверка сумм с продажами, серверный рендер схемы и действий.
- `node --import tsx --test --test-name-pattern='all page components|no key: editor works' tests/render.test.tsx tests/server.test.ts` — 2/2: рендер существующих разделов и сохранение дизайна/конфликты ревизий на отдельной тестовой БД.
- Frontend 5198 запущен, Vite сообщил готовность. API 4198 отвечает; настройки помощника и генерации присутствуют. Live AI-запросы не выполнялись.
- MapLibre составляет отдельный отложенный chunk около 940 kB (256 kB gzip); Vite предупреждает о превышении порога 900 kB. Этот chunk не нужен при открытии обзора или других разделов.
- Визуальная браузерная проверка и скриншоты не выполнены: автоматическая проверка доступа отклонила открытие localhost из-за ранее действовавшего ограничения. Не использовались обходные браузерные инструменты.
- Запрос конфигурации OpenFreeMap из среды разработки вернул HTTP 403. Загрузка географической подложки в браузере пользователя не подтверждена; локальная схема предусмотрена на случай её недоступности. Снимки карты и проверка на физических телефонах отсутствуют.

## Границы текущей реализации

Карта использует демонстрационный справочник, а не GPS/реестр реальных магазинов. Аналитика, кампании и настройки большей частью остаются в браузере; сервер хранит дизайны, материалы, задания и бюджет. Полноценная авторизация организаций, общая серверная аналитика и интеграция кассы/учётной системы не добавлялись. Переключатели ролей — существующая демонстрация интерфейса. Исторические документы в этой копии описывают предыдущую версию; результаты последней проверки приведены здесь.
