# Реализация

1. Прочитать бриф и четыре референса; независимый React/Vite + Node проект.
2. Единое ядро синтетических чеков, расчётов, сегментов, предложений и погашения.
3. Общий интерфейс и четыре утверждённых экрана; затем связанные разделы.
4. SQLite, хранение материалов, версий и реальный API анализа/изображений.
5. Проверка сценариев, адаптивности и скриншоты; отчёт с отдельным статусом live API.
