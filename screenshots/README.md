# Статус скриншотов

Настоящие скриншоты приложения в этой среде **не получены**.

Встроенный браузер трижды отказал в открытии `http://127.0.0.1:5178/overview`: обязательная admin-enforced policy не была проверена, поэтому доступ не предоставлен. Другой механизм управления браузером не использовался для обхода этого ограничения.

Файлы `01-overview.png`, `02-customers.png`, `03-campaigns.png`, `04-coupon-studio.png` не подменены исходными референсами или синтетическими изображениями.

В `e2e/app.spec.ts` подготовлена запись четырёх экранов 1600×1000, дополнительных 1280 и 390, проверка 1440/768, overflow, сохранения, маржи и погашения. Запуск в доступной браузерной среде: сначала `pnpm dev`, затем `pnpm exec playwright install chromium` и `pnpm test:e2e`.
