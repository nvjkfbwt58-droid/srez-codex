Реальные снимки интерфейса получены встроенным браузером и показаны в рабочей беседе: обзор, покупатели, кампании, студия, помощник. DOM-ширины: 320, 390, 768 и 1280 px. Узкие размеры проверены в локальной iframe-оболочке, исключённой из публикации.

Отдельные PNG-файлы экранов не экспортировались. Референсы не подменяют снимки приложения.

Полный `e2e/app.spec.ts` отдельно не запускался. Для запуска: `pnpm dev`, затем `pnpm exec playwright install chromium` и `pnpm test:e2e`. Границы проверки: `PERFORMANCE.md`.
