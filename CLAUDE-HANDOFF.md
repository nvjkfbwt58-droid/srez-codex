# Срез для сетей: исходники для продолжения в Claude Code

Это версия Среза с картой магазинов, а не Пивоман. Снимок от 22.09.2026.
Репозиторий: https://github.com/nvjkfbwt58-droid/srez-codex
Ветка: `srez-network-map-2026-09-22`.

## Быстрый запуск

Нужны Node 24 и pnpm 11. Проверенная среда: Node 24.19.0, pnpm 11.25.0.

```sh
git clone --branch srez-network-map-2026-09-22 --single-branch https://github.com/nvjkfbwt58-droid/srez-codex.git srez-network
cd srez-network
pnpm install --frozen-lockfile
cp .env.example .env
pnpm dev
```

При скачивании ZIP сначала распакуйте его и откройте терминал в папке с `package.json`, затем начните с установки зависимостей.

- Карта магазинов: http://127.0.0.1:5198/stores
- Обзор: http://127.0.0.1:5198/overview
- API: http://127.0.0.1:4198/api/status

```sh
pnpm build
pnpm start
```

Production-запуск после сборки: http://127.0.0.1:4198/overview. Порты фиксированы, сервер слушает только loopback. Для изменения dev-портов согласуйте `vite.config.ts`, PORT и список разрешённых Origin в `server/app.ts`.

## Архитектура и данные

Frontend — React 19, TypeScript, Vite, Zustand. Backend — Express 5 и SQLite в этой же папке `server/`. Начальная SQL-схема лежит в `db/migrations/001-initial.sql`, создание БД выполняется при старте через `server/store.ts`.

Демо-набор создаётся автоматически в новом браузерном профиле: 12 магазинов, 16 000 профилей, 192 товара, 60 670 операций. Расчёты используют целые копейки и демо-даты. Кампании, аналитика и многие настройки хранятся в браузере; backend хранит дизайны, материалы, задания генерации и журнал расходов AI. Реальной общей БД сети, авторизации организаций и кассовой интеграции здесь пока нет. Переключение ролей демонстрационное.

Для изолированной тестовой SQLite и синтетической выгрузки:

```sh
node --import tsx scripts/audit-seed.ts
```

Скрипт всегда создаёт новый временный каталог и печатает manifest с путями. Чтобы использовать его, подставьте пути `directory` и `dotenv` в команду:

```sh
DOTENV_CONFIG_PATH=/NEW_AUDIT_DIR/empty.env OPENAI_API_KEY= IMAGE_PROVIDER=none ASSISTANT_PROVIDER=none AI_BUDGET_USD=0 DATA_DIR=/NEW_AUDIT_DIR PORT=4198 pnpm dev
```

Применяйте чистый браузерный профиль и свободные порты. Скрипт не создаёт настоящие аккаунты: их серверной реализации ещё нет. Серверные fixtures дизайнов не являются автоматическим импортом кампаний в browser storage.

## AI и карта

Приватный `.env`, API-ключи, рабочая SQLite и загруженные пользователем материалы не опубликованы. `.env.example` безопасно отключает AI и задаёт нулевой бюджет. Ручная студия и локальные ответы помощника доступны без ключей.

Для live AI нужны свой серверный `OPENAI_API_KEY`, `IMAGE_PROVIDER=openai` и/или `ASSISTANT_PROVIDER=openai`, согласованный `AI_BUDGET_USD` и доступные аккаунту модели. Названия моделей сохранены из предыдущей реализации; их доступность получателю не проверялась. Локальный счётчик бюджета не равен балансу аккаунта. Все параметры перечислены в `.env.example`. Никогда не помещайте ключ в `VITE_*` или браузерный код.

Карта использует MapLibre/OpenFreeMap; при недоступности подложки доступна локальная условная схема с выбором магазинов. Координаты магазинов демонстрационные. Подробнее: `NETWORK-MAP-UPDATE.md`.

## Проверки и ограничения

```sh
node --import tsx --test tests/networkMap.test.tsx
node --import tsx --test --test-name-pattern='all page components|no key: editor works' tests/render.test.tsx tests/server.test.ts
pnpm test
```

До публикации были выполнены первые две команды: 6/6 целевых тестов. TypeScript, frontend build и backend build прошли. Полный набор `pnpm test` после карты не запускался. Браузерная визуальная проверка заблокирована инструментом доступа; географическая подложка в браузере и физические мобильные устройства не проверены. Платные AI-запросы не выполнялись. Исторические отчёты описывают базовую версию; актуальный отчёт — `NETWORK-MAP-UPDATE.md`.

Все исходники frontend/backend, изображения, зависимости, lockfile, SQL, тесты и скрипты включены. `node_modules` и сборки восстанавливаются приведёнными командами. Публикация исходников в этой ветке не подтверждает соответствие работающего GitHub Pages сайта этой версии.
