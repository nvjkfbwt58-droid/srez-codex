# Отчёт по реализации Среза

Дата работы: 15.09.2026. Фиксированная дата данных: 14.09.2026, 10:00, Москва.

## Итог и границы приёмки

Создан отдельный проект `srez-codex` с работающими frontend/backend, исходниками, lockfile, пятью оригинальными предметными ассетами, тремя темами, общей моделью данных и тестами. Приложение запущено локально на **127.0.0.1:5178**; сервер на **127.0.0.1:4178**. HTTP-запуск подтверждён; тесты и сборка выполнены.

**Полная приёмка задания не заявляется.** Не выполнены браузерные сценарии и визуальное сравнение со скриншотами: встроенный браузер трижды отказал в открытии localhost из-за недоступной проверки обязательной административной политики. Это не ошибка HTTP-сервера. Обход другим способом управления браузером не выполнялся. Live API также не проверен: сервер работает без ключа.

## Стек и запуск

React 19.1.1, TypeScript 5.9.2, Vite 7.1.4, React Router 7.8.2, Motion 12.23.12, Zustand 5.0.8, TanStack Table 8.21.3, Lucide, Inter с кириллицей. Backend: Node 24.19.0 в проверенной среде, Express 5.1.0, встроенный SQLite, OpenAI SDK 6.2.0, Zod, Sharp, PDF.js, локальные файлы. Графики — общие SVG; PNG — html-to-image; QR — qrcode.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
```

`npm run dev` также является единым запуском обоих процессов после установки. Подробности подключения AI и production-запуска — в README.

Чистая установка по lockfile проверена в отдельной папке `/private/tmp/srez-clean-install-0915`: 247 пакетов, успешный exit code 0. Первоначальная offline-попытка не нашла пакет в локальном кэше; установка с разрешённым доступом к registry завершилась успешно.

## Данные

12 магазинов; 16 000 профилей; 192 товара; четыре категории; 102 798 операций. Генератор детерминирован и запускается в Web Worker, затем хранится в IndexedDB. Контрольные суммы в README и автоматическом выводе тестов.

Поведенческая аудитория CP-104 — 2 398. Последовательные исключения: 444 + 211 + 195; доступно 1 548. При контроле 50%: 774 / 774. Для одного получателя потолок 50 ₽, обязательство по скидкам 38 700 ₽. Данные концептуального изображения не подставляются в интерфейс отдельно от чеков.

## Визуал и скриншоты

Все четыре исходных референса открыты и изучены до построения интерфейса. Реализованы общий sidebar 224 px, светлая рабочая область, графитовый график, киноварный акцент, карточная сетка, встроенный профиль и студия с крупным купоном. Отдельно созданы и просмотрены пять предметных сцен, без запечённых UI-надписей.

Настоящие скриншоты `01-overview.png`, `02-customers.png`, `03-campaigns.png`, `04-coupon-studio.png` **не созданы**. Итоговое сходство, размеры 1600/1440/1280/768/390, overflow и reduced motion **не подтверждены браузером**.

Подготовлен `e2e/app.spec.ts`: фильтр → CSV, правило сегмента → профиль/чек, кампания → студия → сохранение/reload, маржа → запуск → касса → повторный отказ; снимки четырёх экранов и брейкпоинтов. Этот файл поставлен, но его выполнение не заявляется. Инструкция — `screenshots/README.md`.

## Что остаётся проверить

- Полная ручная и E2E-проверка пользовательских действий в доступном браузере, включая реальный PNG/CSV download, reload/back/forward, клавиатуру, focus trap, анимации и узкие экраны.
- Визуальное сопоставление четырёх страниц с refs и целевой проход правок по настоящим скриншотам.
- Анализ → генерация → текстовая правка с реальным серверным API-ключом и доступом к выбранным моделям.
- Фактическое время реакции интерфейса и частота кадров. Тесты измеряют выполнение кода Node, но не доказывают 60 fps в браузере.
- WebMCP предусмотрен с feature detection; регистрация/вызовы в поддерживающем браузере не проверены.

Операционные ограничения концепта: локальные роли без production-защиты; нет кассовой интеграции/рассылок/платежей; стоимость внешнего API не оценивалась выдуманными тарифами. Bootstrap-интервал CP-097 взят из заданного fixture, а не перенесён на новую аудиторию. Свойства и результат реализации Claude не исследовались и не оцениваются.
