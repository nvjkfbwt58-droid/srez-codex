# Локальная интеграция OpenAI — 15.09.2026

Исходники AI подготовлены к публикации поверх версии 2117f58623ba0647da01ff460551c33d30b737ba. Наличие кода на GitHub не означает развёртывание backend: публичный AI требует отдельного сервера. Точный SHA этой фиксации сообщается отдельно.

## Что работает

- Помощник: GPT-5.6 Luna, Responses API, структурированный ответ, последние 6 пар сообщений. Отмена, ошибки без подмены ответом заглушки, идемпотентность, ограничения размера/частоты. Ответ появляется над вопросом с существующей анимацией.
- В контекст передаются агрегаты выбранного периода, сравнение, дни, магазины, категории, до 100 товаров по выручке и до 20 кампаний. Сырые чеки, даты рождения и контакты не передаются. Это снимок браузерных данных, не fine-tuning и не подключение к Битриксу.
- Изображения: GPT Image 2.5 Sunburst. Генерация и edits через официальный SDK. Исходник правки идёт первым, референсы ограничены по размеру. Портрет 1024×1536, карточка 1024×1024, баннер 1536×1024. По умолчанию один вариант высокого качества.
- Бренд-анализ: GPT-4.1, профиль по Zod-схеме, источники и черновик на подтверждение.
- Логотип, условия и текст остаются отдельными слоями. Команды «Заголовок: …», «Описание: …», «Убери описание» меняют редактируемый текст без платной генерации; undo работает.

## Настройка и запуск

Node 24, pnpm 11.19.0. Зависимости и lockfile не менялись.

```sh
pnpm install --frozen-lockfile
cp .env.example .env
# Заполнить OPENAI_API_KEY только в серверном .env
pnpm dev
pnpm test
pnpm build
```

Frontend http://127.0.0.1:5178, сервер http://127.0.0.1:4178. Ключ не передаётся браузеру. Локальный `.env` игнорируется, права 0600. Файлы `.env` и storage не публиковать.

Новые переменные: `ASSISTANT_MODEL=gpt-5.6-luna`, `ASSISTANT_PROVIDER=openai`, `AI_BUDGET_USD=5`. `ASSISTANT_PROVIDER=none` отключает чат, `IMAGE_PROVIDER=none` — изображения и анализ. Остальные переменные описаны в `.env.example` и AUDIT-HANDOFF.md.

Для независимой проверки использовать `scripts/audit-seed.ts`, новый DATA_DIR, пустой ключ и `ASSISTANT_PROVIDER=none IMAGE_PROVIDER=none AI_BUDGET_USD=0`. Существующую рабочую БД не копировать и не сбрасывать.

## Расходы

Локальный накопительный лимит сохраняется в SQLite как записи `ai-spend`. До запроса резервируется минимум $0.50 за стандартное изображение GPT Image 2.5 (больше при длинном контексте), $0.50 за анализ, $0.05 за чат. Неизвестные модели изображений сохраняют резерв $2. Это консервативная оценка, а не тариф за картинку. После ответа оценка уточняется по usage. Нет автоматических повторов. При неизвестном исходе или цене резерв остаётся. После отмены ожидания отправленный Images API запрос продолжает учитываться до получения usage; его изображение в купон не применяется. При рестарте/таймауте, когда usage потерян, резерв остаётся. Перезапуск не обнуляет его.

Это учёт данного сервера, не баланс OpenAI и не платёжный лимит всего аккаунта. Кэшированные токены оцениваются по полной цене; фактическое списание сверять в кабинете провайдера. Смена DATA_DIR создаёт другой счётчик. Цены проверены по https://developers.openai.com/api/docs/pricing.

## Ограничения

Только локальное подключение. GitHub Pages продолжает использовать прежний автономный режим. Для публичного AI нужен отдельно размещённый backend с авторизацией; текущий loopback-сервер не подготовлен к открытому доступу. Нет Bitrix-интеграции, production-аккаунтов и защищённой мультиарендности. Качество всех произвольных запросов/брендбуков не гарантируется. Другие периоды запрашиваются через фильтры панели. Полный мобильный и E2E-проход новой AI-версии не завершён: пользователь забрал её на самостоятельную проверку.

Исправление раннего ограничения: два отменённых запроса 15.09 с известными параметрами (Sunburst, high, портрет, 3 референса) удерживали по $2. Их резерв уточнён до $0.50 каждый с сохранением статуса неизвестного расхода и причины изменения. Это не признание отменённых запросов бесплатными. Новые отмены проверены тестом на последующее получение usage.

После исправления лимита: 18 профильных AI/серверных тестов проходят, TypeScript проходит. Предыдущее полное прохождение — 44 теста; новый тест отмены добавлен сверх них. Текущий сервер перезагружен с исправлением, публикация не выполнялась.

Подготовка публикации: полный прогон 45/45 успешен. Рабочая БД, ключи, AI-CHECK изображения и локальные результаты в GitHub не включаются. Публичная Pages-сборка сохраняет автономный режим до размещения backend. Обсуждается размещение на сервере Selectel; доступ к серверу и настройки AI-роутера ещё не предоставлены.
